# TaskMind--Simples-Profissional-e-Facil-de-Lembrar
TaskMind é uma aplicação web desktop de organização pessoal e profissional, desenvolvida para centralizar tarefas, compromissos e hábitos em um único lugar. O projeto foi desenvolvido para facilitar o planejamento e a organização da rotina, permitindo acompanhar atividades e seus respectivos status de forma simples e intuitiva.
