# TaskMind--Simples-Profissional-e-Facil-de-Lembrar
TaskMind é uma aplicação web desktop de organização pessoal e profissional, desenvolvida para centralizar tarefas, compromissos e hábitos em um único lugar. O projeto foi pensado para facilitar o planejamento da rotina, permitindo acompanhar atividades e seus respectivos status de forma simples e intuitiva.
